# 📊 Retail Sales Forecasting Project

This project focuses on forecasting retail sales using time series analysis and machine learning techniques. The goal is to provide accurate sales predictions to support business planning, inventory management, and strategic decision-making.

---

## 🔍 Dataset

- **Source:** [Sales Forecasting Dataset on Kaggle](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting)
- **Description:**  
  This dataset contains historical sales data including daily sales amounts across multiple stores and products. It is ideal for building time series forecasting models.
- **Key Columns:**  
  - `Date`: The date of the sales record  
  - `Store`: Store identifier  
  - `Dept`: Department or product category  
  - `Weekly_Sales`: Sales amount for the week  

---

## 🛠️ Technologies Used

- Python 3  
- pandas for data manipulation  
- matplotlib and seaborn for data visualization  
- Prophet for time series forecasting  
- scikit-learn for model evaluation metrics  
- Jupyter Notebook for development and presentation  

---

## 📈 Project Highlights

- Data cleaning and preprocessing including handling missing values and outliers  
- Aggregation of sales data to weekly and monthly levels to reduce noise  
- Time series forecasting using Prophet to capture trends and seasonality  
- Model evaluation using MAE, RMSE, and percentage error metrics  
- Visualization of sales trends, forecast results, and error analysis  
- Business insights and actionable recommendations based on forecast results  

---

## 📊 Results Summary

- Achieved a Mean Absolute Error (MAE) of approximately 19.16% on average monthly sales  
- Root Mean Squared Error (RMSE) around 27.79% relative to average monthly sales  
- Identified clear sales trends and seasonal patterns useful for inventory and staffing decisions
